# 第一阶段用户验收

从 Codex 新聊天启动“Codex CDP 外部执行验收（临时）”。全部步骤必须由外部 Agent 执行；如果执行信息显示 LazyMind 内部执行，本次验收不算通过。

1. 准备步骤完成后，在网页 Panel 审核并继续。
2. 看见“停止窗口已开始”后，在 90 秒内点击 **LazyMind Panel 的停止**，检查原 Codex 轮次被中断。
3. 在 Panel 恢复，确认原聊天继续，不新建 run。
4. 重试步骤会按 Core 预算故意失败三次；自动预算耗尽后，在 Panel 点击重试。
5. 完成审核后回退到准备步骤，确认仍在原聊天重做。

不要点击 Codex 自己的停止按钮来代替第 2 项。没有观察到实际中断，不得写为通过。
